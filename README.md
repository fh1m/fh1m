## Selected work

<p align="center">
  <a href="https://fh1m.github.io/mongla_ws/">
    <img src="https://fh1m.github.io/mongla_ws/assets/diagrams/loop-rate.svg" alt="Mongla loop-rate diagram comparing a 20 Hz companion-computer loop with a 500 Hz board loop" width="900">

**Mongla** — an independent ROS 2 autonomy stack for an underwater vehicle.<br>
The Pi thinks; the board reacts. **500 Hz** control, Hailo-8 perception, right-invariant EKF, and a codebase that labels what is `BENCH`, `BUILT`, `BLOCKED`, or actually `WATER`.

<p align="center">
  <a href="https://github.com/fh1m/Dristy">
    <img src="https://raw.githubusercontent.com/fh1m/Dristy/main/docs/media/brand/hero.png" alt="Dristy vision co-processor" width="900">
  </a>
</p>

**Dristy** — a K210 camera that turns light into a small answer a robot can use.<br>
On-device detection, colour, motion, QR, tags, optical flow; **320×240** input, **25.4 FPS** camera path, no video stream for the flight computer to decode.
